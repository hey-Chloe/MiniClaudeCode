# MiniClaudeCode v4.1 Final

Lightweight autonomous coding agent runtime inspired by Claude Code and OpenHands.

Features:
- Agent Runtime
- Tool Calling
- Workspace isolation
- Sandbox abstraction
- Permission control
- Human approval
- Trace logging
- Benchmark evaluation
- CLI interface

Architecture:

CLI -> Agent Runtime -> LLM Brain -> Tool Harness -> Security -> Sandbox -> Evaluation
